# Documentation

Parabox investigates misalignment propagation through shared work: how agents
reuse others' methods, change the record they inherit, and direct effort toward
work that later agents encounter.

## Use the framework

| Goal | Guide |
|---|---|
| Install and verify the package | [Getting started](getting-started.md) |
| Run the fixed model comparison | [Shared-work suite](shared-work.md) |
| Understand execution and handoffs | [Architecture](architecture.md) |
| Implement a task or runtime | [Adding a task](adding-a-task.md) |
| Interpret outcomes and reproduce analyses | [Reproducibility](reproducibility.md) |
| Handle untrusted code and evidence | [Security](../SECURITY.md) |
| Submit a change | [Contributing](../CONTRIBUTING.md) |
