# Results

No hosted-model results for the integrated public experiment designs are
published in this release. This page will report per-model outcomes, chain-level
denominators, technical failures, and links to the corresponding machine-readable
evidence when those runs are released.

The other directories under `report/` contain summaries from earlier exploratory
studies, not results for the integrated protocols. See the source-checkout
[historical study guide](../parabox/studies/README.md) before interpreting them.
